This repository contains the data and code needed to reproduce the population assessment model results for Antarctic blue whales, which is published as:  

Rand, Z.R., Olson, P. A., Kinzey, D., Double, M. C., Miller, B. S., Matsuoka K., Findlay, K., and Branch, T. A. (In Review) Critically Endangered Antarctic blue whales are increasing but still far from pre-whaling levels. <i> Endangered Species Research. </i>

Note that this does not include the data and code for the creation of the photo-identification abundance estimate. For more inforamtion about this, please contact paula.olson@noaa.gov.
