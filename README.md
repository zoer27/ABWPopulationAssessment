This repository contains the data and code needed to reproduce the results in the Antarctic blue whale population assessment, which is published as:  

Rand, Z.R., Olson, P. A., Kinzey, D., Double, M. C., Miller, B. S., Matsuoka K., Findlay, K., and Branch, T. A. (In Review) Critically Endangered Antarctic blue whales are increasing but still far from pre-whaling levels. <i> Endangered Species Research. </i>
